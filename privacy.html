NoWayBro policies

Privacy Policy

What this public site collects, and how the separate private production tool handles channel data. Effective date: on first publication of this website.

Operator and contact

NoWayBro is operated by Pujari Sailesh. Privacy questions, access requests and deletion requests can be sent to jerkinsailesh@gmail.com.

This public website

The site is static. NoWayBro has not added a contact form, visitor account, advertising pixel, first-party analytics script or first-party tracking cookie. If you email us, we receive your email address and message so we can respond. Message retention is described below.

When this site is published, GitHub Pages will host it and may process technical request data under the GitHub Privacy Statement. External channel links take you to sites with their own privacy practices.

How the private application works

NoWayBro HQ is a separate operator-only production tool. It helps the authorized channel operator plan topics, create and quality-check short videos, and upload passing videos to YouTube as private. The operator decides when to make a video public. This public site has no login, OAuth connection button, or access to the private dashboard.

Current and planned social integrations

YouTube is the only connected social integration. The private n8n workflow uses the operator's Google/YouTube authorization to upload videos and save the returned YouTube video ID. A separate, currently inactive analytics workflow is configured to request video statistics for previously uploaded videos when the operator runs it. We do not use the public website to request authorization from visitors.

TikTok and Facebook Page have only local metadata-planning code. No TikTok or Facebook account is connected, and NoWayBro currently does not request their OAuth permissions, collect their account data, or upload to them. This policy will be updated before either integration is activated.

Account information and records

For the authorized YouTube channel, the application can receive the video ID returned by an upload and, when its analytics collector runs, the returned video ID, view count, like count and comment count. The exact Google OAuth permissions are those shown to the operator on Google's consent screen; they must be verified against the live credential before broader access is offered. The current workflows do not collect viewers' account details, watch histories, passwords or contacts.

Locally retained production records include job and batch IDs, topic and script data, source notes, generated media, quality-check results, intended publication times, YouTube video IDs, upload outcomes, and any analytics snapshots collected. These records support production, duplicate-upload prevention, troubleshooting and channel performance review.

OAuth tokens and access

OAuth tokens are kept in the private n8n credential store, not in this public website, browser JavaScript, or the public GitHub repository. n8n encrypts saved credentials in its database; its encryption key is not part of this site. The operator is responsible for restricting access to the n8n instance and key. We do not ask for or store Google account passwords. You may revoke NoWayBro's access in Google Account permissions and ask us to remove locally held data using our data deletion instructions. See also the Google Privacy Policy.

Retention and deletion

Our approved retention schedule is: resolved contact messages for up to 90 days after resolution; temporary production assets for 30 days after a confirmed successful upload; and routine backups for 30 days. Original scripts and final master videos are retained until the operator deletes them. The operator-controlled cleanup tool protects active jobs, incomplete batches and uncertain uploads. Pujari Sailesh is responsible for daily operator-run retention reviews; cleanup is not automatically scheduled. Historical workflow and recovery snapshots are classified and held for separate review; they are not routine backups.

YouTube API data has separate requirements. Authorized statistics can be retained while access and video existence are rechecked at least every 30 days; other authorized API data generally must be refreshed or removed within 30 days. Recurring authorization and video-existence review is operator-managed; it is not an automatic feature of this public site. Records without current verification are identified for review and removal. For deletion requests, the operator checks active storage and backups separately and removes relevant data as soon as possible. See the data deletion page. Removing local records does not remove videos or data held by YouTube.

Other services

The private production workflow sends operator-selected prompts or media inputs to OpenAI for AI-assisted scripts, images, narration and transcription; uses Pexels for stock-footage search and downloads; and reads public NASA feeds for research candidates. On publication, GitHub will host this public site and may process technical request data under its Privacy Statement. A normal website visit does not send your personal data to OpenAI, Pexels or NASA through NoWayBro. Following social links takes you to those platforms and their own policies.

Updates

We will update this policy if the website or connected services change. For privacy questions or requests, contact jerkinsailesh@gmail.com. The private workflow uses YouTube API Services; authorized users are also subject to the YouTube Terms of Service.
